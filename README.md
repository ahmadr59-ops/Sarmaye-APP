# سرمایه — Sarmaye

PWA فارسی مدیریت مالی شخصی، حساب‌ها، پیامک بانکی، بودجه، وام و ارزش دارایی.
کد اجرایی در `index.html`، تنظیمات نصب در `manifest.json` و کش آفلاین در `sw.js` است.
داده اصلی روی دستگاه در IndexedDB نگهداری می‌شود؛ localStorage ذخیره جایگزین است.
این پروژه پوشش بومی iOS ندارد.

## اجرای محلی

```sh
python -m http.server 8000
```

آدرس `http://localhost:8000` را در یک پروفایل آزمایشی باز کنید.
برای بررسی ایزوله، حساب Firebase یا توکن GitHub واقعی وارد نکنید.
اتصال شبکه را برای آزمون‌های خطا شبیه‌سازی کنید.

## آزمون

Node.js 24 یا جدیدتر:

```sh
npm ci --ignore-scripts
npm test
```

تست‌های حسابداری، smoke و سناریوهای خطا اجرا می‌شوند. تست‌های جدید از DOM واقعی
jsdom و پیاده‌سازی fake-indexeddb استفاده می‌کنند؛ شبکه واقعی ندارند.
این ابزارها وابستگی توسعه‌اند و در اجرای اپ بارگذاری نمی‌شوند.
موفقیت تست‌ها معادل تأیید Safari یا iPhone واقعی نیست.

## پشتیبان و بازیابی

- Firebase دستی است؛ ورود یا فرستادن اپ به پس‌زمینه، بکاپ موجود را بازنویسی نمی‌کند.
- در ذخیره دستی Firebase می‌توان رمز تعیین کرد؛ یک نسخه قبلی نیز نگهداری می‌شود.
- پشتیبان خودکار GitHub در صورت متفاوت‌بودن نسخه مقصد متوقف می‌شود؛ جایگزینی
  از دستگاه جدید یا متفاوت باید دستی تأیید شود. GitHub همگام‌سازی چنددستگاهی نیست.
- بازیابی فایل، GitHub و Firebase به اعتبارسنجی، تأیید و نگهداری نسخه بازگشت متصل‌اند.
- مسیر «خروجی پشتیبان» دکمه «بازگشت از بازیابی قبلی» را نیز دارد.
- در خطای ذخیره یا تعارض پنجره‌ها، پیش از بازگشایی خروجی نجات بگیرید.

ملاحظات تغییرات و آزمون پیش از انتشار در [RELIABILITY_NOTES.md](RELIABILITY_NOTES.md) آمده است.

## نسخه v24.31 — استفاده روزمره

خانه خلوت‌تر، ثبت سریع با دسته‌های پرکاربرد، بررسی خلاصه پیامک، گردش حساب،
جزئیات تراکنش و گزارش قابل پیگیری اضافه شده‌اند. بودجه هر ماه مستقل است؛
پرداخت وام از همان بخش قابل اصلاح است و وضعیت ارسال به املاک/صرافی
از ثبت نهایی در مقصد تفکیک می‌شود.

تغییرات، معیارهای آزمون و محدودیت‌ها در [DAILY_USE_NOTES.md](DAILY_USE_NOTES.md) آمده است.

## نسخه v24.32 — پاک‌سازی رابط

کارت‌های مخفی و مسیرهای تکراری حذف شدند؛ پشتیبان و بازیابی از
«بیشتر ← حفاظت اطلاعات» در دسترس‌اند. ابزارهای ورود داده و حواله قدیمی
در تنظیمات پیشرفته قرار دارند. داده تاریخی و سازگاری بازیابی نسخه‌های قبلی حفظ شده است.

## نسخه v24.33 — پیامک و دسته‌بندی

در صف پیامک، «نادیده و حذف از صف» با بازگردانی فوری اضافه شده است.
نام و آیکون دسته از مدیریت دسته‌ها قابل ویرایش است و شناسه و اتصال سوابق حفظ می‌شود.
قواعد پیشنهاد دسته از همان بخش یا فرم بررسی پیامک قابل تنظیم‌اند؛ ثبت خودکار انجام نمی‌شود.

## نسخه v24.34 — وام و سررسید مشخص

در «وام و اقساط»، برای وام قدیمی یک‌بار «تعیین شروع پیگیری» را انجام دهید.
پرداخت، تاریخ واقعی و سررسید مستقل دارد؛ پرداخت ناقص تا تکمیل مبلغ باز می‌ماند.
اصل وام از سود آینده جداست. برداشت موجود یا پیامک پرداخت قبلی قابل اتصال است تا دوباره برداشت نشود.
برنامه اولیه با سود ثابتِ پیش‌فرض ساخته می‌شود و جدول بانک مرجع اصلاح تاریخ و مبلغ هر سررسید است.
